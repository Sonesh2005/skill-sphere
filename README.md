
# Skill Sphere 

**Skill Sphere** is an AI-powered, open-source web application designed to revolutionize skill development and job readiness among Indian youth—especially in Tier 2 and Tier 3 regions. The platform offers personalized learning paths, AI-based mentoring, and smart job matching, leveraging open-source AI technologies.

## Features

- AI-driven skill assessment using NLP
- Personalized learning path recommendations
- Voice-enabled AI career mentor (multilingual)
- Job and internship matching
- Gamified progress tracking
- Admin dashboard for institutions & NGOs

## Tech Stack

**Frontend:** React.js, Tailwind CSS  
**Backend:** FastAPI / Flask  
**Database:** PostgreSQL, MongoDB  
**AI/ML:** BERT, SBERT, Hugging Face Transformers, LightFM, Scikit-learn  
**Voice AI:** Whisper, Vosk, Coqui TTS  
**Deployment:** Docker, Netlify/Vercel, AWS/GCP  
**Auth:** OAuth2.0  
**Analytics:** Google Analytics, Prometheus
